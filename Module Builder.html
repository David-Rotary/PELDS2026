Module BuilderCreate content for the President-Elect Toolkit — no coding needed

How it works

  1. Fill in the module details, then add pages with the buttons below — Read, Scenario, Reflect, Quiz and more.
  2. Watch the preview on the right. Click a page to preview it.
  3. Click Save module file. It downloads a small .js file (check your Downloads folder).
  4. Send that file to the toolkit coordinator. Or add it yourself: copy it into the modules folder and add its name to modules/_module-list.js.
  5. To test it straight away, open START HERE.html and click Try a module file on the home page.

Formatting: leave a blank line between paragraphs · start a line with - for a bullet · **bold** · *italic* · > for a highlighted box · [link text](resources/file.pdf) to link a document in the resources folder.
Writing tips: make scenarios real dilemmas with no obvious answer · give every choice an honest outcome · ask reflection questions that only the President-Elect can answer about their club.

Your work is kept in this browser as you type, but Save module file is the only way to keep it safe.
